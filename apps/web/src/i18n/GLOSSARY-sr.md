# Serbian (sr-Latn) glossary

Serbian in **Latin script**, ekavian (as used by Serbian-speaking communities and institutions in
Kosovo). Address patients formally (**Vi**, polite plural imperative: "Dodajte", "Otvorite",
"Izaberite"). Keep sentence case and placeholders such as `{name}` and `{count}` exactly.
Use the same term everywhere.
